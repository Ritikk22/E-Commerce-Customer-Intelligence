# E-Commerce Customer Intelligence and Purchase Prediction Using Machine Learning

## 🚀 Live Web Application

**Click here to use the application:**

[Open E-Commerce Customer Intelligence Dashboard](https://e-commerce-customer-intelligence-4cx2wcghwtfdm7tbxsqqbm.streamlit.app/)

## 📌 Project Overview

This project uses Machine Learning to analyze customer purchasing behaviour,
segment customers, and predict purchase behaviour.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## 🤖 Machine Learning Algorithms

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)
6. K-Means Clustering

## 📊 Main Features

- Customer segmentation using K-Means
- RFM analysis
- Purchase behaviour prediction
- Machine Learning model comparison
- Interactive dashboard
- Business recommendations
